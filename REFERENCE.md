# Clean-room reference notes

The installed Retrograde 1.0.0 bundle was inspected only for externally observable metadata and behaviour.

- Bundle identifier: `com.SimonServida.Retrograde`
- Architecture: Intel `x86_64` only
- Framework: JUCE, VST3 SDK 3.7.2
- Externally visible concepts: independent left/right time, left/right tempo sync, and rhythmic subdivisions

ReverseLab uses new source code, identifiers, UI, parameter IDs, presets, and DSP implementation. No Retrograde binary or asset is copied into this repository.
